# Movie Ticket Reservation System (MTRS)

## Project Overview

The Movie Ticket Reservation System is a Database Management
Systems project designed to manage movies, theatres, showtimes,
seat availability, and ticket reservations.

## Objectives

- Manage movie and theatre information.
- Display available movie shows and showtimes.
- Allow customers to reserve seats.
- Maintain booking records.
- Support booking cancellation.
- Generate booking and revenue reports.
- Demonstrate relational database concepts.

## Technology Stack

- Frontend: HTML, CSS, JavaScript
- Backend: Java with Spring Boot
- Database: MySQL
- Database Connectivity: JDBC
- Version Control: Git and GitHub

## Planned Database Tables

1. Users
2. Movies
3. Theatres
4. Screens
5. Seats
6. Shows
7. Bookings
8. Booking_Seats
